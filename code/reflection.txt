Assignment #1 was very helpful in many different ways. One of the ways
in which it was most helpful, however, was that it helped me get familiar
with using GitHub. I was introduced to running tests, debugging, how to
push, fork, and just learning the layout. Because of this assignment, I
now feel more confident using GitHub for future assignments and projects.

On the more technical side of this reflection, I learned how different
functions work together and how unit tests and integration tests can be
used to find mistakes in my code. For example, when working on
grand_total(), one of my tests failed because my function was not
returning the expected value. I learned to look at the assertion to
understand what was wrong instead of just guessing. I also learned how a
small mistake can affect an entire program. When I used subtotal instead
of total in console.py, it caused the integration test to fail.

The part I struggled with most was using the debugger. I understood how
to set a breakpoint, but I was sometimes unsure what to look for when the
program paused. I want more practice using the debugger to follow my
variables and understand how my code is running. For future assignments,
I will use a breakpoint and step through my code when a test fails before
changing my code. I will also practice reading the assertion and checking
my variables to find where the error is coming from. Overall, this
assignment helped me become more comfortable with Python, testing,
debugging, and GitHub.
